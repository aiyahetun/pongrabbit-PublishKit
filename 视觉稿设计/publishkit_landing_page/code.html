常见问题 (FAQ)

help 数据真的完全保存在本地吗？

是的。PublishKit 采用本地优先架构，所有文章、草稿和发布记录都默认存储在你的设备上，确保你的数据隐私与安全。

help 为什么不支持一键分发？

各平台的排版规则和流量机制不同。我们鼓励回到原生平台完成最后一步操作，以确保最佳的展示效果。PublishKit 的核心在于帮你清晰地“准备内容”和“管理台账”，而不是粗放的分发。

help 浏览器插件支持哪些浏览器？

目前支持所有基于 Chromium 内核的浏览器，包括 Chrome、Edge、Brave 等。
