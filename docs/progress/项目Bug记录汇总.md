## 二、状态说明

| 状态 | 含义 |
|------|------|
| 未修 | 已确认，未开始修复 |
| 修复中 | 已有 PR / 分支，未验收 |
| 已修复 · 待验收 | 代码已合，待自测或用户确认 |
| 已修复 · 生产验收通过 | 对应版本已发布且验证通过 |
| 已缓解 | 有 workaround 或文档约束，未彻底根治 |
| 不修 / 设计如此 | 经评审确认非缺陷 |
| 已修复 · 文档 | 仅文档类条目使用 |
