# PublishKit 开发环境

## 已安装 / 已配置

| 项 | 状态 |
|----|------|
| Node.js | v24+ |
| npm workspaces | 根目录 `package.json` |
| Rust (rustup) | 通过 winget 安装；若编译失败见下方 |
| 工程 | `apps/desktop` — Tauri 2 + Vue 3 |

## 首次在本机运行

```powershell
cd C:\Users\win\Desktop\内容营销平台工具
npm install
npm run check:i18n
npm run tauri dev
```

> `npm run tauri dev` 会在根目录执行，等价于 `apps/desktop` 里的 Tauri 开发模式。

## 若 Rust / 链接报错

Tauri Windows 还需要 **MSVC 构建工具**（C++）：

1. 打开 https://visualstudio.microsoft.com/visual-cpp-build-tools/
2. 安装「使用 C++ 的桌面开发」
3. 重新打开终端，执行：

```powershell
rustup default stable
npm run tauri dev
```

## 当前 M1 已实现

- 选择文案 / 图片文件夹（系统文件夹对话框）
- 扫描文件夹内 `.md` / `.txt` 并列表展示
- **Markdown 拆分向导**（整篇 / `##` / `#01` 款式编号）→ 导入 SQLite
- **内容**页：条目列表 + 一键复制正文
- 界面中/英切换（设置页），启动时读系统语言或已保存偏好
- i18n key 一致性检查：`npm run check:i18n`

## 打包 Windows 安装包（F10）

```powershell
cd C:\Users\win\Desktop\内容营销平台工具
npm run build:desktop
```

产物目录（默认）：

```text
apps/desktop/src-tauri/target/release/bundle/nsis/PublishKit_*_x64-setup.exe
apps/desktop/src-tauri/target/release/bundle/msi/PublishKit_*_x64_en-US.msi
```

首次打包需已安装 MSVC 构建工具（见上文）。打包前会自动执行 `npm run build` 构建前端。

## GitHub Release（CI）

推送 **版本 tag** 后，`.github/workflows/release.yml` 在 Windows runner 上构建 NSIS 安装包，并创建 **Draft Release**（预发布）：

```powershell
git tag v0.1.9
git push origin main
git push origin v0.1.9
```

在 GitHub → Releases 中检查草稿、编辑说明后发布。本地与 CI 版本号需一致（`package.json` · `tauri.conf.json` · `Cargo.toml`）。
