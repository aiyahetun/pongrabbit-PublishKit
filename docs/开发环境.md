# PublishKit 开发环境

## 已安装 / 已配置

| 项 | 状态 |
|----|------|
| Node.js | v24+ |
| npm workspaces | 根目录 `package.json` |
| Rust (rustup) | 通过 winget 安装；若编译失败见下方 |
| 工程 | `apps/desktop` — Tauri 2 + Vue 3 |

## 首次在本机运行

```powershell
cd C:\Users\win\Desktop\内容营销平台工具
npm install
npm run check:i18n
npm run tauri dev
```

> `npm run tauri dev` 会在根目录执行，等价于 `apps/desktop` 里的 Tauri 开发模式。

## 若 Rust / 链接报错

Tauri Windows 还需要 **MSVC 构建工具**（C++）：

1. 打开 https://visualstudio.microsoft.com/visual-cpp-build-tools/
2. 安装「使用 C++ 的桌面开发」
3. 重新打开终端，执行：

```powershell
rustup default stable
npm run tauri dev
```

## 打包 Windows 安装包（F10）

```powershell
cd C:\Users\win\Desktop\内容营销平台工具
npm run build:desktop
```

产物目录（默认）：

```text
apps/desktop/src-tauri/target/release/bundle/nsis/PublishKit_*_x64-setup.exe
apps/desktop/src-tauri/target/release/bundle/msi/PublishKit_*_x64_en-US.msi
```

首次打包需已安装 MSVC 构建工具（见上文）。打包前会自动执行 `npm run build` 构建前端。

## GitHub Release（CI）

推送 **版本 tag** 后，`.github/workflows/release.yml` 会同时打三份安装包，并发布为该 tag 的 Release（成功后即成为 Latest）：

- Windows：`windows-latest`，`PublishKit_*_x64-setup.exe`
- macOS Apple 芯片：`macos-latest`，`aarch64-apple-darwin`，`PublishKit_*_aarch64.dmg`
- macOS Intel：`macos-latest`，`x86_64-apple-darwin`，`PublishKit_*_x64.dmg`

这台 Windows 电脑打不出 dmg。Mac 包只在 GitHub Actions 的 macOS 机器上生成。安装包没有代码签名。

```powershell
git tag v0.3.12
git push origin main
git push origin v0.3.12
```

tag 上的版本号要和 `package.json`、`tauri.conf.json`、`Cargo.toml` 一致。网页上的下载按钮按 `website/assets/site.js` 里的 `version` 去取 `releases/download/v版本号/` 下的这三个文件名。先等 Actions 三份都上传完，再把网页传到线上，否则按钮会落到还没有的文件。
