# PublishKit · 排期导入、关联词井号与按钮层级方案

| 属性 | 内容 |
|------|------|

| 对应使用问题 | 一批稿子要手建成待发任务；有的平台复制关联词要带 `#`，有的不要；按钮字偏大，一屏里分不出主操作 |

| 产品边界 | 本地内容资产和发布台账。导入只生成待发任务。用户仍在各平台自己的发布页粘贴。不接账号，不代发 |

0.3.8 定案：

- 排期导入一次选多份文案或一张表。先拆出标题、正文、关联词，预览里可以取消勾选。再填发布起始日、间隔天数、发布平台，确认后按「一条内容 × 一个平台」写入待发任务。
- 表里已有日期或平台列时，以那一行为准。没有日期的稿件从起始日按间隔排开。间隔填 0，选中的稿件都在起始日。同一篇在勾选的每个平台上各一条，日期相同。
- 导入进当前顶栏选中的项目。新内容是新增，不覆盖已经入库的同名文件。免费版仍是 50 条内容，超了整批不写入。
- 模板只给两份，在排期导入里下载。文案用 Markdown，一行一条的排期用 Excel。Word 沿用同一套字段名，不另做 pdf、html 模板。
- 关联词在库里继续不带 `#`。要不要井号记在渠道上，复制关联词时再选。同一批词可以发给小红书（带 `#`）和知乎（不带）。
- 一块区域只有一个金色主按钮。复制正文是复制区的主按钮。标为已发布用绿色，不再和复制正文抢同一个金色。
- 日历可以导出一段日期里的发布记录。可选全部项目或其中几个。一行是一条内容在一个平台上的任务。表是 xlsx。
- 任务条上有「关联素材」。草稿、待发（含逾期）、已发布都能点。图挂在内容上，同一内容的几个平台共用这一组。
- 排期可以带配图。文稿写 `**配图：**`，表格用「配图」列，按文件名对当前项目已经扫进图片库的图。预览里可以取消勾选。库里没有的名字写在这一行上，这一行仍能建成待发。
- 发布平台列表里没有要发的平台时，在排期导入里填写名称并添加。新平台记入全库渠道，当场勾上，设置里也能看到。

## 1. 别人怎么排，我们取哪一种

看的是「一批稿怎么进日历」和「标签要不要带井号」。他们的自动发帖、账号托管不采用。

| 产品 | 他们怎么做 | 出处 | 发稿匣采用的部分 |
|------|------------|------|------------------|
| Buffer | 按渠道上传 CSV。一行一条。列有 Text、Image URL、Tags、Posting Time。时间可空，空则进该渠道的下一个队列空档。时间格式要求 `YYYY-MM-DD HH:mm`，Excel 自动改日期格式是他们文档里点名的失败原因 | [Bulk upload](https://support.buffer.com/articles/how-to-upload-posts-in-bulk-to-buffer-cTIhl4mv6H) | 一行或一节是一条内容。表里有日期就用那一天。日期单独解析，不依赖 Excel 存成什么显示格式 |
| Publer | CSV 有 Date 列，建议 `YYYY/MM/DD`。日期可空，空的行在导入后用界面统一指定排期方式。上传后先看到每条，再点 Submit | [CSV 模板](https://publer.com/help/en/article/what-csv-template-should-i-use-18qhxcq/)、[批量排期](https://publer.com/help/en/article/how-to-schedule-in-bulk-using-a-csv-file-3yvwt/) | 先预览，再填起始日和间隔。确认前可以去掉某一条 |
| 蚁小二 | 学院文章里的周度流程是：素材导入，选平台或账号，设定时，预览，再提交。多平台建议错开十几到三十分钟 | [周度排期](https://xueyuan.yixiaoer.cn/article/46522) | 选文件、选平台、填日期、看一遍、再创建。错开用「几天一发」，不代发，也不按分钟错峰 |
| Buffer Hashtag Manager | 标签组单独存，发的时候插入正文或第一条评论。设计师写过，用户以前把标签放在备忘录里 | [Hashtags](https://support.buffer.com/article/586-how-hashtags-work-in-buffer) | 关联词仍是内容上的字段。井号不写进词本身，按渠道在复制时加上或去掉 |

不采用的做法：

- 导入后直接发到平台。发稿匣没有账号，任务停在待发，人去各平台粘贴。
- 按 Buffer 的队列空档自动找下一个发布时间。这里没有发布队列，只有用户填的起始日和间隔。
- 把同一篇稿按平台拆成多条内容。渠道文案不同，仍然是另建一条内容。这次导入的多平台共用这一条的标题、正文、关联词。
- 在词上存 `#`。小红书要井号、知乎不要，存进词里就会互相污染。
- 给 Instagram 写死「最多 5 个标签」。平台限额会变，按钮旁不报这个数。
- 把整站按钮换成另一套皮肤。只收字号，并让一块区域里只剩一个金色主按钮。

## 2. 排期导入

入口有两处。「来源文件」里，它是「开始扫描」旁边的次按钮。「任务」页右上角，它是这一排的主按钮。两处打开同一个对话框。

### 2.1 能读的文件

| 扩展名 | 怎么处理 |
|--------|----------|
| `.md` / `.markdown` / `.txt` | 按文案拆 |
| `.docx` | 抽出 Word 正文再拆。飞书、Google 文档导出成 docx 走这一条 |
| `.pdf` | 只抽文字层。扫描件没有文字层，会报读不出 |
| `.html` / `.htm` | 去掉 script、style 和标签，留下文字再拆 |
| `.xlsx` / `.xls` / `.csv` | 按表。一行里的中英对照仍拆成一对内容 |

旧版二进制 `.doc` 不读。请另存为 `.docx`。

文案用现有的智能拆分。有多段被标成建议导入的，只留这些段。一段都没有，整篇当作一条。然后用已经在用的字段解析：同行 `**关联词：**`、换行的 `**标题（中文）**` 这类标签，以及英文 Title / Description / Keywords。中英都标了的块拆成两条，用 `pair_id` 连着。认不出关联词就留空，不从文末猜。

配图同样只认标签。中文是 `**配图：**`、`**图片：**`，英文是 `**Images:**`、`**Image:**`、`**Media:**`。名字可以写在冒号后面，也可以从下一行接着写，直到下一个字段。所以配图放在这一节的最后。顿号、逗号、分号、竖线和换行都会切开；文件名中间的空格留着。这一节的名字抄到这一节拆出来的每一条上，中英一对共用同一组。配图行留在配图里，不写进正文。

表沿用现有的标题、正文、语言、平台、关联词列。另外认日期列，表头命中：`日期`、`发布时间`、`发布日期`、`排期`、`scheduled`、`schedule`、`date`、`postdate`、`publishdate`。日期接受 `2026-10-08`、`2026/10/8`、`2026年10月8日`、带时间的 ISO，以及 Excel 序列号（按 1899-12-30 起算，落在常见表格范围内的整数）。配图列的表头是 `配图`、`images`、`imagefile`。格子里的名字和正文里的配图标签合在一起，标签里的名字在前。

某一份文件读失败，写进对话框底部，其他文件继续。整批都没有正文时，对话框说明这些文件里没有可排期的内容。

### 2.4 给用户的模板

不做每种格式一份。导入只有两条路，模板也是两份，都从「排期导入」里下载。

| 模板 | 适合 | 不适合 |
|------|------|--------|
| 文案模板 `.md` | 一篇篇写。二级标题一节一条。字段用「标题：」「正文：」「关联词：」「配图：」。中英写在同一节，这一节的配图两篇都带上 | 在文件里写发布日期。日期仍在导入窗口里填 |
| 排期表 `.xlsx` | 一行一条。列是标题、正文、关联词、语言、平台、发布日期、配图。日期或平台空着时，用窗口里填的 | 长文的多级标题。那种用文案模板 |

PDF、HTML、TXT 不再单独给模板。它们能导入，但不适合当写作底稿。Word 不另给一份：用「标题 2」和同样的字段名，另存为 `.docx`。飞书、Google 文档导出成 Word 或表格即可。旧版 `.doc` 不读。

文案模板开头的「使用说明」标题里含「说明」，智能拆分会把它当成说明段跳过，不会变成待发任务。排期表里没有说明行，避免把说明导入成一条内容。关联词示例不带 `#`。配图示例是文件名，这些文件要先在当前项目的图片库里。

### 2.2 对话框里填什么

选完文件才出现排期。每一行是一条内容：勾选、标题、算出来的日期、平台、关联词、正文前 120 字、对上的配图、来源文件名。取消勾选后这一行变淡，仍留在列表里，方便再勾回去。取消的行不占间隔名额。配图以缩略图出现，每张可以单独取消。同名有多张、又分不出该用哪一张时，先全部不勾，由人勾选。写了名字但图片库里没有的，这一行仍可创建，并写出没找到的文件名。

三个控件：

- 发布起始日。默认明天。
- 间隔天数。默认 1，可以填 0 到 365。
- 发布平台。芯片多选，数据是全库渠道，含已经添加的自定义渠道。芯片下面可以填写名称、选择国内、海外或两边，再点「添加平台」。名称和已有平台相同（忽略大小写）时，直接勾上那一个，不再另建一条。新平台写入渠道表，市场分组和设置 → 平台用的是同一份。添加后这一颗芯片是勾上的。自定义平台按单框渠道处理：复制正文时，关联词接在正文后面。

日期怎么落到每一行：

1. 这一行自己带了日期（表里的日期列），用那一天。它不占用「第几篇」的名额。
2. 没有自带日期的，按当前仍勾着的顺序：第 1 篇是起始日，第 2 篇是起始日加间隔，依此类推。
3. 间隔是 0 时，这些没有自带日期的稿件都在起始日。
4. 这一行的平台列能对上渠道名或渠道 id 时，用对上的那些渠道，不再用上面勾的芯片。对不上，退回芯片。匹配时忽略单字，避免「X」碰上所有名字里带 x 的渠道。
5. 勾了几个平台，就在同一天建几条任务。

确认按钮写「创建 N 条待发」。N 是勾选行乘上各自平台数。没有平台或没有日期时，这一行不计入，按钮不可用。

### 2.3 写入

确认后一次事务：

- 内容进当前项目。换项目用顶栏页签，对话框里不再单做一个「导入到」。
- 每条新内容新 id。同一路径再导一次是再加一批，不替换旧条目。源文件登记进 `source_documents`，同一路径复用那一条文档记录。
- 关联词去掉用户原稿里已经写上的 `#` 再入库。
- 任务状态直接是 `ready`，并写入 `scheduled_at`。不用普通的「新建任务」，那条命令建的是草稿、没有排期。
- `scheduled_at` 记成当天 `T12:00:00Z`。国内 UTC+8 看日历仍是这一天。
- 同一条内容、同一个渠道已有任务时，跳过这一条任务，不让整批失败。结果句会写出跳过的条数。新导入的内容 id 是新的，正常不会撞上这条唯一约束。
- 免费版按将要新增的内容条数检查 50 条上限。会超出时整批不写，设置里的许可证提示仍是原来的那句。
- 这一行仍勾着的配图，按勾选顺序写进这条内容的关联。只写索引，磁盘上的文件留在原地。图片不属于当前项目，或不是图片，就跳过这一张。没找到的文件名不挡住这条任务。

### 2.5 配图对的是当前项目的图片库

用这个项目已经扫描进来的图片。不再为排期另指定一个文件夹，也不按「随便一个目录里文件名像不像」去扫盘。

对名字的规则：

1. 文稿或表格里写了文件名。图片库里只有一张叫这个名字的图，默认勾上。
2. 同名有多张时，若其中恰好一张在这个项目的图片文件夹里，用那一张，并默认勾上。仍有多张，或一张都不在这个文件夹里，就把这几张都列出来，默认不勾。
3. 写的是带目录的名字，例如 `subdir/cover.jpg`，只认路径末尾能对上的那张。对不上就当没找到，不用另一个目录里碰巧同名的文件顶上。
4. 比较不分大小写。`Cover.JPG` 和 `cover.jpg` 是同一个名字。
5. 这一份文件只拆出一节（中英一对算一节），而且这一节没有写配图：图片主文件名和文案文件名完全相同的才带上，例如 `spring.md` 对 `spring.jpg`，也可以同时对上 `spring.png`。`spring-2.jpg` 这种只是名字里带着 spring 的，不带上。
6. 这一份文件拆出多节时，不按整份文件的主文件名去套图。每一节写自己的配图。
7. 不用标题里的词去猜图。视频不参与这次对名。

任务创建之后仍可以改。任务页和今天的任务条上有「关联素材」，打开的是内容库同一个窗口，改的是这条内容。待发、逾期的待发、草稿、已发布都能点。按钮是灰色文字，复制正文仍是这一排里的金色按钮。

## 3. 关联词是否加 #

井号是渠道的复制格式，不是内容字段。

`channels.keyword_hash`：1 表示复制时加井号，0 表示不加。迁移第 9 步给这些内置渠道设成 1，并且只跑一次：小红书、抖音、快手、视频号、哔哩哔哩、微博、头条、Instagram、TikTok、Threads。之后用户关掉，下次启动不会被重新打开。知乎、公众号、Pinterest、YouTube、Reddit、LinkedIn、Facebook、X、Product Hunt 以及后来新建的自定义渠道，默认不加。

复制条上不再放常驻勾选。点「复制关联词」后，按钮下出现两个选项：「不加 #」和「加 #」。点中哪一个，就按那一种写入剪贴板。这个平台已经记下的选择会高亮，并标成「这个平台默认」。

当前任务带渠道时，这一次的选择同时写回该渠道，作为以后的默认。「复制全文」里的关联词、Chrome 侧栏、渠道发布包里的标签文件，都读这个默认，不再单独追问。内容库没有渠道时，两个选项仍出现，高亮在「不加 #」，选择只影响这一次剪贴板。

设置 → 平台。每个渠道标签上仍有「加 # / 不加 #」，内置渠道和自定义渠道都可以点。它和复制时的选择写的是同一个字段。

加上之后，复制结果是 `#词`，词与词之间一个空格。已经带 `#` 的词不会变成 `##词`。不加时：Pinterest 是逗号加空格；其他有渠道的，词里有汉字用顿号，否则用逗号。内容库没有渠道时，是空格分隔的原词。

「复制正文」在单框渠道（抖音、微博，以及自定义渠道）会在正文后空一行接上这份格式。小红书、Pinterest、公众号、YouTube 的正文不接关联词。「复制全文」是标题、空行、库存正文、空行、这份关联词，纯文本，关联词只出现一次。全文用该平台记下的默认，不弹出选择。

## 4. 按钮层级

[设计标准](设计标准-PublishKit.md) §3.1 原来写主按钮高 32px 或 36px，并且把「标记已发布」列为主按钮。0.3.8 改成下面这套，标准里的 §3.1 已按此更新。

| 类型 | 尺寸 | 用在哪 |
|------|------|--------|
| Primary | 高 30px，字号 13px，字重 600，金色填充 | 一块区域里的那一个主操作。复制正文、开始扫描、任务页的排期导入、新建、保存 |
| Success | 尺寸同 Primary，绿色填充 | 标为已发布、逾期里的补记发布 |
| Secondary | 高 26px，字号 12px，白底描边 | 刷新、导出、来源页的排期导入、选择文件夹 |
| Ghost | 高 26px，字号 12px，字重 400，灰色字，无边框 | 复制标题、复制关联词、复制全文、关联素材、关闭 |

同一块区域仍然只有一个金色按钮。来源页的主按钮是「开始扫描」，排期导入是次按钮。任务页这一排的主按钮是「排期导入」，导出和刷新让开。复制区的主按钮仍是「复制正文」。

页面标题、侧栏导航没有改成按钮样式。配色仍是设计标准里的金色 `#b8924a`。

## 6. 验收

安装 `PublishKit_0.3.12_x64-setup.exe` 之后看这些。第 3 条是复制关联词时的井号选择，第 4 条是日历导出。第 7 条是任务上的关联素材，第 8 条是排期配图。第 9 条是在排期导入里添加自定义平台。

1. 顶栏先选中要导入的项目。来源文件或任务里打开「排期导入」，选一份带 `**标题**` / `**正文**` / `**关联词**` 的 Markdown，预览里是拆开的标题、正文、关联词。填起始日和间隔，勾两个平台，创建之后任务页出现对应条数的待发，日历落在这些日期上。
2. 一张表含标题、正文、日期、平台。有日期的行用表里的日期。没有日期的行从起始日按间隔排。间隔改成 0 后，没有日期的行都显示起始日。取消勾选一行，它留在列表里，确认时不创建。
3. 小红书任务上点「复制关联词」，选「加 #」。剪贴板是 `#词` 空格分隔。「复制全文」里这组词只出现一次，并且跟着刚才的选择。再选「不加 #」，汉字词变成顿号分隔。设置里这个渠道的开关和刚才的选择一致。Pinterest 上高亮的是「不加 #」，选它之后复制是逗号分隔。内容库没有渠道时，两个选项仍出现，选择不改任何平台的默认。
4. 日历点「导出记录」。项目留在全部，日期用当前这一月或这一周，状态是待发、已排期、已发布。表有日期、项目、平台、状态、语言、标题、正文、发布链接、备注。同一篇在两个平台上是两行。已发布的日期是发布当天。只勾一个项目时，另一个项目的行不在表里。草稿默认不在表里。
5. 内容卡片上，金色按钮只有「复制正文」。任务待发状态下，「标为已发布」是绿色。来源页金色按钮是「开始扫描」。日历上的「导出记录」是次按钮。
6. 再导一次同一个文件，内容库多出一批新条目，旧条目还在。免费版在将要超过 50 条时，这一批不会写入。
7. 任务页和今天里，待发（含已经过期的待发）、草稿、已发布的任务条上都有「关联素材」。点开后是内容库同一个窗口。图记在这条内容上，所以同一篇在小红书和 Pinterest 上看到的是同一组图。
8. 文案写 `**配图：** cover.jpg、detail.png`，或排期表的「配图」列写同样的名字。这些文件已经在当前项目图片库里时，预览出现缩略图，默认勾上。取消一张再创建，这条内容不带这张。写了一个库里没有的名字，这一行仍能变成待发，并标出这个名字。一份里面有多节的 Markdown，不会因为文件名相同就把同一张图贴到每一节。一份只有一节、又没写配图，而图片主文件名和文案相同（`spring.md` 与 `spring.jpg`）时，预览会带上这张图。
9. 排期导入里，发布平台下面填一个列表中没有的名称，点「添加平台」。新芯片出现并处于勾选。用它创建的待发，任务上的平台就是这个名称。设置 → 平台里也能看到它。再填一次同一个名称，不会多出第二条，原来的那颗芯片被勾上。

## 8. 日历导出发布记录

入口在日历工具栏，按钮是「导出记录」，次按钮。月视图打开时，起止日期默认这一月。周视图打开时，默认这一周的周一到周日，和周列表同一段。

窗口里三组选择：

- 项目。默认「全部项目」。也可以勾一个或多个未归档或已归档的项目。全部时，范围内已归档项目的任务也写进行。
- 起止日期。含首尾两天。
- 状态。默认勾待发、已排期、已发布，和月历上会出现的状态一致。阻塞、草稿、已归档默认不勾。至少留一种。

一行是一条内容在一个平台上的一条任务。同一篇在小红书和 Pinterest 上是两行。还没有发布链接的行仍保留，链接格留空。

日期和日历用同一天：已发布用 `published_at` 的日期，否则用 `scheduled_at`，再没有就用更新时间。所以一条排在 1 号、3 号才标成已发布的任务，出现在 3 号。

xlsx 只有一张表，表名「发布记录」。列依次是：日期、项目、平台、状态、语言、标题、正文、发布链接、备注。语言写成中文或 English。状态用界面上的词。关联词、配图、账号不进这张表。任务页原有的「导出 CSV」仍是全部任务的另一份清单，不带这段日期和项目筛选，也不含正文。

文件名带项目和日期范围。全部是 `发布记录_全部_2026-10-01_2026-10-31.xlsx`。只选一个项目时用项目名。选了多个是 `发布记录_所选项目_…`。界面语言是英文时，表头和文件名用英文。

排序是日期、项目名、平台名。正文或备注超过 32000 字时截断，避免 Excel 拒收这一格。
