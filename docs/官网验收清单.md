# PublishKit 官网验收清单

适用于 `website/` 静态落地页（中英文）本地预览与上线前检查。

## 一、本地启动

在项目根目录执行：

```powershell
npx --yes serve website
```

浏览器打开：

| 地址 | 说明 |
|------|------|
| http://localhost:3000/ | 根路径，按浏览器语言跳转 `/zh/` 或 `/en/` |
| http://localhost:3000/zh/ | 中文落地页 |
| http://localhost:3000/en/ | 英文落地页 |
| http://localhost:3000/privacy.html | 隐私政策（双语） |

> 端口若被占用，`serve` 会自动换端口，以终端输出为准。

## 二、占位图说明（当前状态）

官网与 Chrome 商店配图**已用 SVG 占位符**，文件名与最终成品一致，便于后续替换：

| 目录 | 用途 |
|------|------|
| `website/assets/images/` | 官网 LP-01～LP-11（图标、favicon、Hero、OG、5 张功能截图） |
| `apps/extension/store/assets/` | Chrome 商店 CWS-01～CWS-08 |

占位图清单见 `website/assets/images/manifest.json`。  
AI 出图描述词见项目根目录 `PublishKit-官网与Chrome商店配图AI描述词.md`。

**验收时预期**：页面能正常显示带虚线框、标注 LP-xx / CWS-xx 的占位 SVG，无 404 裂图。

## 四、上线前必改项（非本次占位验收范围）

编辑 `website/assets/site.js`：

```js
checkoutUrl: {
  en: "", // → Paddle 结账链接
  zh: "", // → 微信 Native 收银链接
},
```

替换占位图为正式 PNG/WebP 后，同步更新 HTML 中 `og:image`、favicon 扩展名（若从 SVG 改为 PNG）。

Chrome 商店上传前，将 `apps/extension/store/assets/*.svg` 导出为 PNG（见 manifest 中 `exportAs` 字段）。

## 五、部署验收（可选）

海外收银 / API 热更另见 [`PublishKit-海外上线前检查.md`](./PublishKit-海外上线前检查.md)，上线前执行：

```powershell
node website/scripts/verify-live.mjs
```

部署到 `get.pongrabbit.com/en/` 与 `get.pongrabbit.cn/zh/` 后，重复第三节 AC1～AC10，并额外确认：

- [ ] HTTPS 证书有效
- [ ] 根域名语言跳转与 CDN 缓存策略正确
- [ ] OG 分享预览图在 Slack / 微信 / X 中显示正常（替换正式 OG 图后）

## 六、快速回归命令

重新生成全部 SVG 占位符：

```powershell
node website/scripts/generate-placeholders.mjs
```

生成后刷新浏览器即可，无需改 HTML。
