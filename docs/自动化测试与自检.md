# PublishKit · 自动化测试与自检

| 字段 | 内容 |
|------|------|
| 文档版本 | v1.0 |
| 编写日期 | 2026-09-02 |
| 适用版本 | v0.2.6+ |

开发完成后，在提交或验收前运行统一自检。本地与 GitHub Actions CI 使用同一套命令。

---

## 1. 一键自检

在项目根目录：

```bash
npm run check
```

等价于 `npm test`。依次执行：

| 步骤 | 命令 | 说明 |
|------|------|------|
| i18n | `check:i18n` | `zh-CN.json` 与 `en.json` key 完全一致 |
| versions | `check:versions` | 根 `package.json`、`apps/desktop`、`Cargo.toml`、`tauri.conf.json` 版本号一致 |
| types | `vue-tsc --noEmit` | 前端 TypeScript 类型检查 |
| frontend | `vite build` | 生产构建（含类型检查） |
| rust | `cargo test` | Rust 单元测试 + `import_self_check` 集成测试 |

任一步失败则整体退出码为 `1`。

---

## 2. 快速自检（日常迭代）

只改 Rust 或只改文案时，可跳过完整前端打包：

```bash
npm run check:quick
```

跳过 `vite build`，仍跑 i18n、版本对齐、vue-tsc、cargo test。

单独跑某一项：

```bash
npm run check:i18n
npm run check:versions
npm run check:rust
npm run typecheck --workspace @publishkit/desktop
```

按步骤子集：

```bash
node scripts/run-checks.mjs --only=i18n,rust
```

## 3. Rust 测试覆盖

| 模块 | 文件 | 内容 |
|------|------|------|
| FTS 搜索 | `db.rs` `fts_tests` | 查询构建、空查询 |
| 重复发布 | `db.rs` `duplicate_publish_tests` | 30 天预警逻辑 |
| 渠道发布包 | `channel_pack.rs` | 小红书/微信/默认模板 |
| MD 拆分 | `md_split.rs` | H2/H3 拆分策略 |
| Word 导入 | `doc_import.rs` | 标题样式解析 |
| 素材推荐 | `media_suggest.rs` | 同目录/镜像目录打分 |
| 多格式导入 | `tests/import_self_check.rs` | docx/pdf/xlsx/csv 端到端 |

仅跑 Rust：

```bash
npm run check:rust
# 或
cd apps/desktop/src-tauri && cargo test
```

---

## 4. CI（GitHub Actions）

推送 `main` 或 PR 时，`.github/workflows/ci.yml` 自动执行 `npm run check`。

Release 仍由 `.github/workflows/release.yml` 在打 `v*` tag 时构建 Windows 安装包。

---

## 5. 建议工作流

### 每次功能开发完成

1. `npm run check:quick`（或全量 `npm run check`）
2. 手动冒烟：`npm run tauri dev`，点一遍改动相关页面
3. 验收通过后：`git commit` + `git push`

### 发版前

1. `npm run check`（全量）
2. `npm run build:desktop`（本地 NSIS 冒烟，可选）
3. 更新 `docs/progress/产品进度一览.md`
4. 打 tag `v0.2.x` 触发 Release 草稿

### 暂不在自动化内（需人工）

| 项 | 原因 |
|----|------|
| Tauri 桌面 UI E2E | 需 WebDriver / 手动点击 |
| 浏览器插件 | 独立 MV3，在 Chrome 里 sideload 验证 |
| i18n 零闪屏 I18N-1~5 | 需英文 OS / 重启观察首帧 |
| 安装包 / 自动更新 | Release 流水线 + 真机安装 |

---

## 6. 新增测试约定

- **Rust 业务逻辑**：优先在对应模块 `#[cfg(test)]` 加单测
- **跨模块流程**：放 `apps/desktop/src-tauri/tests/*.rs`
- **i18n**：新增 key 必须同时写入 `zh-CN.json` 与 `en.json`
- **版本号**：改版本时同步四处（`check:versions` 会拦不一致）

---

## 7. 故障排查

| 现象 | 处理 |
|------|------|
| `cargo test` 在 Linux CI 失败、Windows 通过 | 看是否缺系统库；CI 已装 webkit2gtk |
| `i18n` 失败 | 对比报错 key，补全另一种语言 |
| `versions` 失败 | 对齐 `package.json` / `Cargo.toml` / `tauri.conf.json` |
| `vue-tsc` 失败 | 先 `npm run typecheck --workspace @publishkit/desktop` 看具体文件 |
