# PublishKit / 发稿匣 · Pinterest 营销文案

## 使用说明

**文档版本 v1.6（2026-10-09）· 语气：独立开发者坦白局** · 每张图下标题、正文、关联词可直接贴进 Pin（中英各一套）。下面 §一～§三 是写 Pin 前必读；§0 起是链接、Board、逐图文案。导入排期工具时跳过说明节。

写给自己的备注不要进正文（例如「这张图太小」）。

图上若有「灵感 / 报表」等菜单，是概念图；文案只写已上线能力：内容、素材、任务、今天、日历、复制、标记已发布。

### 一、PublishKit 优势、特点、与同类差异（写文案的锚点）

**我们是谁（一句话）**  
本地桌面 + Chrome 侧栏：帮你把**文案、配图、各渠道版本、发没发、链接在哪**管在一起；**帖仍在你自己的浏览器里发**，我们不拿平台密码，也不自动发帖。

**用户真痛点（Pin 从这里起笔，不要从功能名起笔）**

| 痛点 | 用户心里那句话 | 我们怎么接 |
|------|----------------|------------|
| 找不到 | 「这篇到底发没发？链接又在哪？」 | 一条内容 × 一个渠道一行状态，链接可回填 |
| 贴错了 | 「怎么把小红书那段贴进 Pinterest 了…」 | 侧栏按渠道复制，不是同一个剪贴板糊全场 |
| 版本乱 | 「Pin 标题、笔记正文、YouTube 简介开了三个文档」 | 同一条下面分渠道备稿 |
| 表格崩 | 「飞书/Excel 拉长就对不上哪天发哪条」 | 周历 + 今天，专看排期与待发 |
| 不敢交号 | 「调度器要 OAuth，矩阵工具要绑一堆号」 | 本机 SQLite，插件只连 127.0.0.1 |
| 订阅疲劳 | 「又一个按月、按渠道加钱」 | Free 50 条 + Pro **买断** |

**和三类常见工具的边界（对外要说人话，不要只背对比表）**

| 对比对象 | 他们卖什么 | 我们不一样在哪 |
|----------|------------|----------------|
| **Buffer / Later / Hootsuite** | 「帮你定时发出去」「你睡觉它也发」 | 我们：**你亲手点发送**；我们记的是**发完之后的台账**，适合怕风控、不想交 OAuth 的人 |
| **蚁小二等矩阵/一键分发** | 「多账号、一键发布、更轻松」 | 我们：**不绑你的号**；同一篇稿是**多版本正文**，不是同一段话糊到全网 |
| **Notion / 表格 / 模板** | 「有个日历格子」 | 我们是**发帖现场能用**的：浏览器开着编辑页，侧栏就在旁边复制 |

**对外只强调、不夸大的特点**

- 桌面 Windows（另有 macOS 包）+ Chrome 插件「发稿匣助手」配对后，在**发帖页旁边**复制、标记已发布、抓当前页链接。  
- 中英可拆成关联条目；渠道发布包、重复链接提醒（Pro）等见官网。  
- **不代发、不托管账号**——这是信任卖点，不是道歉；语气用「账号还在你浏览器里」，少用冷冰冰的「本产品不支持」。

### 二、同类营销文案调研（2026-10，公开页面摘录）

用来学**语气和结构**，不要抄成「我们也自动发」。

| 来源 | 典型说法 | 语气特征 |
|------|----------|----------|
| [Buffer · Pinterest](https://buffer.com/pinterest) | *Drive more traffic…* · *Think of Buffer as your Pinterest virtual assistant* · *staying consistent on Pinterest a breeze* | 结果 + 轻松 + 「你」；把工具拟人成助手 |
| [Later · Pinterest Scheduler](https://later.com/pinterest-scheduler/) | *Reach new customers* · *Planning & posting made simple* · *automatically post in advance* | 增长导向；强调「提前安排好」 |
| [Loomly](https://www.loomly.com/) | *Stress-free social media management* · *Plan weeks, or months of content in minutes* | 减压词 + 时间数字 |
| [蚁小二官网](https://www.yxiaoer.cn/) | *让新媒体运营更轻松* · *矩阵管理、一键发布* | 省力、矩阵、一键（**我们反面参照**） |
| [发稿匣官网](https://get.pongrabbit.cn/zh/) | *跨境内容发文，不再乱、不再慢、不再忘* · *你手动发、我们帮你记* | 三字痛点 + 手动发边界清晰 |
| [Voltis Content Calendar](https://voltislabs.uk/product-content-calendar) | *without spreadsheets, without a server* · *the plan, not the pipe* | 本地、不是 scheduler——和 PublishKit 最接近的叙事 |

**可借鉴的写法**

- 中文：先一句**场景吐槽**（翻聊天、贴错渠道、三个 Word），再**「所以做了这个」**或**「我是这样用的」**，最后一句动作（复制 → 发 → 记链接）。  
- 英文：以 **You / Your** 或问句开头；**PublishKit** 放在第二句；避免 *PublishKit is a…* 词典定义。  
- 热词：**自然塞进正文一次**即可（内容日历、content planner、pinterest planner…）；标题像人起的，不像 SEO 生成器。  
- 仍遵守 Pin 研究习惯：描述靠前出现品牌名；英文约 220 字符内；说清一件事。

**故意不用的词（标题 / 标签）**  
一键分发、矩阵运营、social media scheduler、template 主词——会引来「要自动发帖」的人。

**搜索量参考（仍有效）**  
英文：content calendar、content planner、social media content calendar、social media tracker、youtube planner、pinterest planner。中文：内容日历、多平台发布、自媒体工具、小红书运营、今天发什么。

### 三、v1.6 Pin 怎么写（独立开发者坦白局）

像 Indie Hackers / Show HN 发帖，不像品牌通稿。

1. **人设**：做跨境内容的**一个人**（或小团队），工具是**自用做出来、顺手开源/上架**的；不装大厂，不喊「赋能」「矩阵」。  
2. **标题**：坦白动机或翻车——*我做 X 是因为…* / *别指望它能…* / *如果你要 Buffer 那种请划走*；可夹 1 个搜索词（内容日历、content planner）。  
3. **正文四段**（短）：① 我当时的真痛点 ② 我怎么做的边界（手动发、本地、不 OAuth）③ 你怎么用一遍 ④ 谁适合 / 价格（敢说「不适合想要自动发的人」）。  
4. **英文**：*I built…* / *I ship…* / *Wrong tool if…*；第二句 PublishKit；可以 *honest limit:* 一句。  
5. **「不代发」**：用开发者口吻——「我故意不做自动发」而不是「本产品不支持」。  
6. **关联词**：仍从下面池子选 5～8 个，正文里自然出现一次即可。
